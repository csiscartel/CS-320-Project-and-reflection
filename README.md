## Reflection Questions

### How can I ensure that my code, program, or software is functional and secure?

Firstly, I created a comprehensive JUnit testing case. Ensuring that my code behaves exactly as expected under all circumstances. I also ensure that invalid data never make it way to the system. These are added security and functionality. 
Lastly, I understand that security is key to sensitive applications. I applied so many security methods. I also anticipated users’ inputs that were not mentioned in the requirement that could possibly break in production. Focusing on data integrity was my primary concern.

### How do I interpret user needs and incorporate them into a program?


I begin by analyzing the requirements. I then break the requirements down into manageable test cases and start applying test techniques ensuring that code behavior is the expected behavior. When I unexpectedly outcome or edge cases I hadn’t considered, I refined the code to the user needs. 

### How do I approach designing software?

My software design approach follows several key principles that I applied consistently across all three services: 
My approach to software design follows several key principles:

Separation of concerns, Defensive design, testability by design, and documentation through code. For separation of concerns, I created classes that represented only its data and validation rules were also enforced by the class.  In defensive design, I assumed that callers might put invalid input. Public parameters were first validated before proceeding and throwing exceptions that were very descriptive. For Testability by design, I structured my code in a way that it will be easily testable. I used dependency injections making the methods to only focus on single responsibility. For documentation, I followed naming conventions rules for classes and methods and properly annotate each and every step.
